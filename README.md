# 5 ways to torcher a ceiling
This is a game made for the hack club event horizons arcana by Erin, Shelley and Shurui. For this project we got the theme of a photo of this seal called ceiling! So we decided to torcher it hahahaha. 

# User Instructions
To access this game go to [insert itch link]

It first starts off with an animation of a killer whale grabbing a seal, the seal is then put into a detainment chamber. 

You can attack ceiling by 4 different methods, by tasing ceiling, punching ceiling, punching ceiling and frying ceiling (??). 

Ceiling has a dark secret,,, and it can only be revealed by clearing all 4 levels and beating the information out of ceiling

<img width="1153" height="658" alt="image" src="https://github.com/user-attachments/assets/cd2df918-331b-4638-a2a0-a640a4444647" />

As you can see on the options on the bottom. as well as a life bar. When you click on an attack option, a pop up will appear with the order of keys you need to hit. If you hit the correct keys in the correct order, ceiling will take damage. The first level requires 4 combos to receive the first piece of information. 

Pieces of information are stored in the journal which is in the top left corner of the screen, everytime a scene is finished the info will be stored
